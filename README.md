# Coverage

เว็บอธิบายประกันชีวิตแบบสะสมทรัพย์ในไทย ใส่อายุ เพศ และทุนประกัน แล้วดูว่าแต่ละแบบจ่ายเท่าไร ได้คืนเท่าไร ถ้าเลิกกลางทางได้เท่าไร และลดหย่อนภาษีได้แค่ไหน

เว็บนี้อธิบายตัวเลขเท่านั้น ไม่ได้แนะนำว่าแบบไหนเหมาะกับใคร ตัวเลขทุกตัวมาจากเอกสารทางการของบริษัทประกันหรือธนาคารผู้ขาย และไม่ใช่ใบเสนอราคา

## มีอะไรบ้าง

- **ค้นหาประกัน** (`/`): เทียบทุกแบบตามโปรไฟล์ของคุณ เลือกเป้าหมายหรือเรียงตามตัวเลขที่สนใจได้
- **หน้าแต่ละแบบ** (`/products/[id]`): สรุปแบบเข้าใจง่าย ตารางรายปี ทางเลือกเมื่อหยุดจ่ายเบี้ย และกราฟเทียบเงินที่จ่ายกับเงินที่ได้คืน
- **เทียบ** (`/compare`): วางหลายแบบเทียบกันในตารางเดียว
- **วางแผนภาษี** (`/tax`): ดูว่าเบี้ยประกันช่วยลดภาษีได้เท่าไรตามฐานภาษีของคุณ

ข้อมูลที่กรอกเก็บอยู่ใน URL ไม่มีการเข้าสู่ระบบและไม่มีเซิร์ฟเวอร์เก็บข้อมูล แชร์ลิงก์ได้เลย

## หลักการของตัวเลข

- ตัวเลขหลักคือ **ผลตอบแทนที่รับประกัน (IRR)** ถ้าถือจนครบสัญญา
- เงินปันผลแสดงเป็นเส้นประและติดป้าย "ไม่รับประกัน" เสมอ
- ถ้าอายุและเพศตรงกับตารางเบี้ยของบริษัท จะคิดจากตารางนั้น ถ้าไม่ตรงจะใช้ตัวอย่างในโบรชัวร์และบอกไว้ชัดเจน
- ถ้าบริษัทไม่เผยแพร่มูลค่าเวนคืน ช่องนั้นจะว่าง ไม่มีการเดาตัวเลข

## เริ่มใช้งาน

ต้องใช้ Node.js 24 ขึ้นไป

```sh
npm install
npm run dev        # http://localhost:3000
```

คำสั่งอื่น

```sh
npm test           # Vitest
npm run typecheck  # tsc
npm run build      # สร้างเว็บแบบ static
npm start          # รันเว็บที่ build แล้ว
```

## โครงสร้าง

- `fixtures/` ข้อมูลแบบประกัน หนึ่งไฟล์ JSON ต่อหนึ่งแบบ ค่าเงินเก็บเป็นบาทต่อทุนประกัน 1,000 บาท
- `src/domain/` schema (Zod) การคำนวณเบี้ย ผลตอบแทน ทางเลือกเมื่อหยุดจ่าย และภาษี
- `src/web/` ตัวช่วยฝั่งหน้าเว็บ เช่น การจัดรูปแบบตัวเลขและการอ่านค่าจาก URL
- `app/` หน้าเว็บ Next.js (App Router สร้างทุกหน้าเป็น static ตอน build)

## เพิ่มหรือแก้ข้อมูลแบบประกัน

1. สร้างหรือแก้ไฟล์ใน `fixtures/` ตาม `ProductSchema` ใน `src/domain/product.ts`
2. ใส่ `source.url` และ `source.documentTitle` ให้ชี้ไปเอกสารที่ใช้จริง
3. ใช้เฉพาะตัวเลขที่บริษัทเผยแพร่ ถ้าไม่มีมูลค่าเวนคืนให้ใส่ `cashValue: null`
4. รัน `npm test` ทุกไฟล์ใน `fixtures/` จะถูกตรวจด้วย schema

## ข้อจำกัด

- ยังไม่คิดส่วนลดเบี้ยสำหรับทุนประกันสูง เบี้ยที่แสดงจึงอาจสูงกว่าจริงเล็กน้อย
- ความคุ้มครองอุบัติเหตุแสดงเป็นข้อความ ยังไม่รวมในตารางและกราฟ
- ข้อมูลอาจล้าสมัยเมื่อบริษัทเปลี่ยนแบบประกัน ดูวันที่ดึงข้อมูลได้ท้ายหน้าแต่ละแบบ
